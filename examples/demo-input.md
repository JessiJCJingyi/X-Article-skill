# 演示输入：会议笔记整理

以下作者设定、语料和场景均为虚构演示，不代表真实人物经历或已验证成绩。正式使用时替换为自己的材料。

## 任务
- 主题：如何把会议笔记整理成可执行的待办。
- 读者：刚开始负责项目协调的人。
- 交付：X 长文操作手册；默认完整内容包。
- 读完能做什么：把讨论记录整理成动作、负责人、时间及待确认项。
- 案例：使用虚构会议，不能编造作者实绩。

## 作者与表达
- 演示定位：分享日常办公方法。
- 可公开语料：无真实个人经历。文章采用中性说明，示例明确标注。
- 仅学习表达的虚构样句：“会上说了很多，散会后却没人知道下一步归谁。先把动作和负责人写在一起。”
- 避免：保证提高多少效率、虚构客户故事、空泛的行业趋势。

## 内容素材
虚构会议只提供以下信息：
- 需要修改活动报名页面。
- 设计负责人尚未确定。
- 希望周五前完成，但没有人确认可行。
请把确定的事项与待确认的事项分开，不自行补负责人姓名或截止时间承诺。

## 视觉
- 米白背景，深蓝文字，橙色只用于关键动作。
- 宽体标题，正文易读；不要仿造真实产品界面。
- 四张图可分别解释：输入分类、待办字段、未确认事项、发布前检查。
- 5:2 封面短标题：“会议笔记怎么整理”。
- 这些只是演示偏好，不是所有用户的默认风格。
